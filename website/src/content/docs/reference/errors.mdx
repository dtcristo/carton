Carton's own errors subclass `Carton::Error`. Every Box shares these classes, so `rescue Carton::Error` works in the app and inside any Carton. Otherwise Carton raises what Ruby would: `LoadError` for a missing import target, and `ArgumentError` for `export` without exactly one value.

```
StandardError
└── Carton::Error
    ├── Carton::ImportError
    ├── Carton::ExportError
    └── Carton::GemfileNotFound
```

## `Carton::Error`

<Signature owner="Carton::Error" rbs="class Carton::Error < ::StandardError" source="lib/carton/error.rb#L6" />

The base class of every error Carton raises itself. Carton never raises it directly.

## `Carton::ImportError`

<Signature owner="Carton::ImportError" rbs="class Carton::ImportError < Carton::Error" source="lib/carton/error.rb#L12" />

An import that cannot go ahead.

<Tag label="Raises">

- Raised by [`import`](/reference/kernel/#import) and [`import_relative`](/reference/kernel/#import_relative) when:
  - Boxes are disabled; run Ruby with `RUBY_BOX=1`.
  - The target is a file in a Carton's Interior; only its Entrypoint can be imported.
  - The target is not Ruby source, such as a native extension found on `$LOAD_PATH`; only a `.rb` Entrypoint can be imported.
  - The import is circular, including a Carton importing itself.
  - A Shared Import finds a Gem Carton built against other gem versions than this import activates or locks. The message names the gem and both versions.

</Tag>

## `Carton::ExportError`

<Signature owner="Carton::ExportError" rbs="class Carton::ExportError < Carton::Error" source="lib/carton/error.rb#L17" />

A missing or invalid Export.

<Tag label="Raises">

- Raised by [`export`](/reference/kernel/#export) on a second call while an Entrypoint loads, or for a Symbol. Once the Import finishes, a call from the Entrypoint's methods is inert.
- Raised by [`import`](/reference/kernel/#import) or [`import_relative`](/reference/kernel/#import_relative) when the Entrypoint finishes loading without calling `export`. An `export` in a required file does not count.

</Tag>

## `Carton::GemfileNotFound`

<Signature owner="Carton::GemfileNotFound" rbs="class Carton::GemfileNotFound < Carton::Error" source="lib/carton/error.rb#L21" />

<Tag label="Raises">

- Raised by [`Carton.setup_bundle`](/reference/carton/#setup_bundle) when it finds no Gemfile: none at `gemfile:`, or no `gems.rb` or `Gemfile` from the calling file's directory upward.

</Tag>
