The smallest working app with Carton boundaries, with no gems or Bundler. Then see [Exports](/guides/examples/exports/) for Hashes, callables, and an explicit adapter for legacy Ruby. [Source on GitHub](https://github.com/dtcristo/carton/tree/main/examples/minimal).

```
main.rb              # imports billing and math
billing.rb           # the billing Carton's Entrypoint: export Billing
billing/invoice.rb   # inside the billing Carton
billing/tax.rb       # inside too; imports math
math.rb              # a Carton of one file: export MathTools
```

## The billing Carton

`billing.rb` is the Entrypoint. It loads its own files with `require_relative`, all inside the billing Carton Box, hides `Billing::Tax` with `private_constant`, and exports `Billing`:

`billing/tax.rb` imports `math`, another Carton, across a boundary. The app imports `math` too, so that import is a Shared Import and both get the same Export:
