A Rack app is any object that responds to `call(env)`, so a Carton can export one. Here a plain `config.ru` mounts two domain Cartons with Rack's `map`, with no web framework. [Source on GitHub](https://github.com/dtcristo/carton/tree/main/examples/rack).

```
Gemfile                      # carton, rack; rackup and webrick to serve
config.ru                    # the host: mounts each Carton's Rack app
main.rb                      # sends requests with Rack::MockRequest
cartons/
  catalog/
    lib/catalog.rb           # Entrypoint: export Catalog, a Rack app
    lib/catalog/products.rb  # inside the Carton; private
  orders/
    lib/orders.rb            # Entrypoint: imports catalog, exports a lambda
test/app_test.rb
```

## Run

```sh
bundle exec rake example:rack
RUBY_BOX=1 ruby examples/rack/main.rb
cd examples/rack && RUBY_BOX=1 bundle exec rackup   # serves on port 9292
```

```
GET /catalog => {"tea":450,"coffee":600}
GET /orders/quote?sku=tea&quantity=2 => {"sku":"tea","total":900}
GET /orders/quote?sku=cake&quantity=1 => 404

```
