An import returns the Entrypoint's Export, or a `Carton::Namespace` for a Bare Carton. [minimal](/guides/examples/minimal/) exports a module; this example covers a Hash, a callable, and an existing file with no `export`. It needs no gems or Bundler. [Source on GitHub](https://github.com/dtcristo/carton/tree/main/examples/exports).

| File | Import returns | How the app uses it |
| --- | --- | --- |
| `settings.rb` | A plain Hash from `export currency: 'USD'` | Pattern matching extracts `currency` |
| `formatter.rb` | A Proc | `money.call(4_200)` formats cents |
| `legacy.rb` | A `Carton::Namespace`, since the file has no `export` | `Legacy.label(42)`, `Legacy::PREFIX`, or pattern matching |

## The app

<ExampleFile path="exports/main.rb" />

`Legacy` exposes the Entrypoint's constants and Helpers; the Carton Box stays private. Pattern matching captures the Helper as a `Method`, which the app calls with `.call`. New Cartons should export a deliberate value; Bare Cartons let existing code load unchanged.

Every Shared Import returns the same Export or Namespace. If you export a mutable Hash, every Importer gets that same Hash, so freeze it if it is meant to be read-only.

## Run

```sh
RUBY_BOX=1 ruby examples/exports/main.rb
```

```text
INV-0042: USD 42.00
Captured Helper: INV-0007
Legacy prefix: INV
PREFIX defined in Main: false
```
