An import returns exactly the Entrypoint's Export. [Minimal](/guides/examples/minimal/) exports a module; this example covers a Hash, a callable, and a distinct adapter Entrypoint for an existing file with no `export`. It needs no gems or Bundler. [Source on GitHub](https://github.com/dtcristo/carton/tree/main/examples/exports).

| File | Import returns | How the app uses it |
| --- | --- | --- |
| `settings.rb` | A plain Hash from `export currency: 'USD'` | Pattern matching extracts `currency` |
| `formatter.rb` | A Proc | `money.call(4_200)` formats cents |
| `legacy_adapter.rb` | A plain Hash containing `prefix` and a captured `label` method | Pattern matching extracts values; `label.call(42)` calls the method |

## The app

<ExampleFile path="exports/main.rb" />

The app binds the adapter's Hash to `legacy`, then extracts `label` and `prefix` through pattern matching. `label` is a `Method`, which the app calls with `.call`. The original file stays unchanged, and the adapter chooses what crosses the Carton boundary.

Every Shared Import returns the same Export. If you export a mutable Hash, every Importer gets that same Hash, so freeze it if it is meant to be read-only.

## Run

```sh
RUBY_BOX=1 ruby examples/exports/main.rb
```

```text
INV-0042: USD 42.00
Captured method: INV-0007
Legacy prefix: INV
PREFIX defined in Main: false
```
