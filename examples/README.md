# Examples

Each directory is a separate, runnable program. Their guides, with the code and how to run each one, are at https://carton.dtcristo.com/guides/examples/.

From the repository root:

```sh
bundle install
bundle exec rake example:minimal   # one example
bundle exec rake examples          # every example
```

Unsupported and private-runtime experiments live in [spikes/](../spikes/README.md).
